# Gear Guru Guide: YouTube Review Workflow for the 100-Item Catalog

## Editorial Model

The catalog is a **research system**, not a promise to publish one hundred standalone reviews immediately. Use it to create a focused YouTube series: one decision-led anchor video each week, supported by one 30–60 second short and a matching article update. The review remains your editorial work even where a product link is later approved.

> A product is not “best selling” because it appears in a search result. Use an explicit, date-stamped Amazon category rank or an approved product-data source before making that claim. Otherwise describe it as an **Amazon-listed candidate** or a **research-track product**.

## Required Review Structure

Each video should open with the actual trip context, declare what is manufacturer-stated versus independently observed, and explain what the review cannot prove. Include the full ownership system: price checked on date, required accessory or plan, power source, carry weight, service, warranty, and repair path. End with a clear “skip if” statement.

| Segment | Purpose | Required language |
|---|---|---|
| **0:00–0:20** | Hook and buyer problem | Never say “best” or “top-selling” without recorded evidence. |
| **0:20–1:00** | Who this is for / skip if | Name the realistic user and the wrong-fit user. |
| **1:00–4:00** | System evidence | Separate manufacturer claims from observed findings. |
| **4:00–6:00** | Total ownership | Cover power, plans, accessories, repair, and use friction. |
| **6:00–7:00** | Verdict and next action | Give an independent decision, then point to the guide. |

## Sponsorship, Endorsement, and Link Rules

Any payment, gifted product, sponsorship, or endorsement relationship must be declared in the YouTube video and description. The Gear Guru Guide public site’s disclosure remains the canonical policy. Do not accept terms that require an unqualified positive review, suppress material limitations, or demand hidden commercial content. An approved affiliate link is not an endorsement; an endorsement is a separate editorial and commercial decision.

## Amazon Review Procedure

If Amazon Associates approves the site, choose an Amazon product only from the generated linking tools or approved API response. Record the date, ASIN, product condition, seller, fulfillment status, listed price, and explicit category rank before using any “best seller” claim. If no explicit rank is visible, use neutral wording and place the link only next to a clearly disclosed, independent review.
